# pi-cinlodev-cute 🌸💜

> Visual suite and aesthetic personality pack for Pi Coding Agent and la Gentlewoman.

## Features

- 🎨 **Cinlodev CUTE Theme**: Deep obsidian background (`#1A1218`), vibrant dark violet borders (`#8e44ad`), pastel pink accents (`#F095C8` / `#FFB1DD`), and golden headings (`#E0C27A`).
- 👑 **la Gentlewoman Welcome Dashboard**: High-density upper header with git branch, model, profile, tools count, skills, and double-line violet framing. Expandable/collapsible with `Ctrl+O`.
- 🎛️ **Cinlodev CUTE HUD Widget**: Real-time persistent metrics widget above the prompt displaying session cost, context window usage, tokens, and active directory.
- 💬 **Double-Line Violet Prompt Editor**: Custom terminal input frame with spinning flower indicator (`✿ ❀ ❁ ✾`), pastel pink block cursor, and double border rails.
- 🛡️ **Update-Proof Architecture**: Lives in its own package and GitHub repository, protecting all customizations from third-party resets or upstream package updates.

## Installation

```bash
pi install git:github.com/CinloDev/pi-cinlodev-cute
```

Or for local development:
```bash
pi install /path/to/pi-cinlodev-cute
```

## Commands

- `/hud` — Toggle persistent HUD above input (`/hud`, `/hud full`, `/hud compact`, `/hud off`).
- `/welcome` — Toggle or configure the upper Welcome Dashboard.
- `/cinlodev` — Reapply and verify all Cinlodev CUTE interface components.
